# Logos

- `drawpane-mark.svg`: the two-pane mark for light grounds. The back pane is outlined in `#1c1b19` (Paper `ink`) and the front pane is filled `#e04f1a` (Paper `signal`).
- `drawpane-mark-graphite.svg`: the same mark for dark grounds, outlined in `#f2f0eb` (Graphite `ink`) with the front pane in `#ff7a45` (Graphite `signal`).
- `drawpane-mark-mono.svg`: single ink `#1c1b19`, for one-color print and embossing.
- `drawpane-app-icon.svg`: the app and favicon tile on a `#1c1b19` ground with a 14/64 corner radius.

Keep clear space of half the mark's width on every side, at a minimum size of 16px. Never recolor the panes, add effects, or rotate the mark. An outlined wordmark is not produced yet: set "Drawpane" in Instrument Sans 600 beside the mark.

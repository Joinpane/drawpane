# Workspace

The Drawpane editor composed entirely from this system, in both themes. Use it as the reference layout for the file pane, command strip, share strip, Layers and Inspector panes, Selection Lens, Layout X-ray and collaborator presence.

**Consumer provides:** nothing. This is a showcase page, not an exported component.

- Panes float 12px from the window edge and from each other. The canvas is always visible between them.
- The design on the canvas uses the file's own colors and never follows the UI theme.
- Only one signal-filled control appears (Share). Signal also marks the active tool, the selected layer and the selection on the canvas, because all of them mean "you".
